# LaTeX 文档项目集合

这是一个综合的 LaTeX 文档项目仓库，包含多种类型的学术文档、模板和实际应用案例。项目主要围绕学术写作、竞赛报告和产品文档展开，提供了完整的 LaTeX 解决方案。

## 📋 项目概述

本项目集合了以下几个主要方面的 LaTeX 文档：

- **学术产品文档**：方言自适应学习系统的产品说明书和技术方案
- **数学建模竞赛**：全国大学生数学建模竞赛 CUMCM 的完整项目
- **LaTeX 模板库**：多所知名院校的论文/报告模板集合
- **日常文档管理**：学术文章、作业、比赛等文档的分类管理

## 📁 项目结构

```text

├── 产品说明书/          # 方言学习系统产品说明书（清华模板）
```

## 🛠️ 使用方法

### 环境要求

- **LaTeX 发行版**：TeX Live 2020+ 或 MiKTeX
- **推荐编译器**：XeLaTeX（支持中文和现代字体）
- **参考文献工具**：Biber

### 编译步骤

以数学建模项目为例：

```bash
cd model/
xelatex main.tex
biber main
xelatex main.tex
xelatex main.tex
```

或使用 latexmk（推荐）：

```bash
latexmk -xelatex main.tex
```

### 模板使用

1. **选择合适的模板**：从 `Template/` 文件夹选择对应院校的模板
2. **复制基础文件**：将模板文件复制到工作目录
3. **修改内容**：根据需要修改 `.tex` 文件内容
4. **编译生成**：使用相应的编译命令生成 PDF

## 💡 使用建议

1. **选择合适的编译器**：
   - 中文文档推荐 XeLaTeX
   - 纯英文文档可使用 PDFLaTeX
   - 需要复杂字体支持时使用 LuaLaTeX

2. **文件组织**：
   - 将图片放在 `figures/` 目录
   - 章节内容模块化管理
   - 参考文献使用 `.bib` 文件统一管理

3. **版本控制**：
   - 使用 Git 管理源码
   - 忽略编译生成的临时文件
   - 重要版本及时备份

## 🔧 故障排除

### 常见问题

1. **字体问题**：
   - Windows 系统使用 `fontset=windows`
   - macOS 系统使用 `fontset=mac`
   - Linux 系统使用 `fontset=ubuntu` 或 `fontset=fandol`

2. **编译错误**：
   - 确保所有宏包已正确安装
   - 检查文件路径和引用
   - 查看 `.log` 文件获取详细错误信息

3. **参考文献问题**：
   - 确保使用 `biber` 而不是 `bibtex`
   - 检查 `.bib` 文件格式
   - 运行完整的编译序列
